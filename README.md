# 📊 Python Data Analysis & Processing

Most real-world data (especially LLM outputs) is messy, unstructured, and full of noise. I built these Python scripts to take chaotic raw data and turn it into something that actually makes sense.

This repo contains the toolkit I use for scientific problem-solving, filtering out experimental noise, and running statistical variance checks.

### ⚙️ What's inside:
- **analysis_toolkit.py**: Custom modules to break down raw datasets and calculate variance without relying on heavy external bloatware.
- **dataset_processor.py**: Scripts for data modeling and linear regression to format and calibrate complex measurements.

### 🧠 Why this matters for AI Evaluation:
You can't properly benchmark an AI if you don't know how to handle unpredictable data. The logic and noise-reduction techniques I use here to clean complex scientific data are the exact same mechanics needed to parse, clean, and structure messy LLM outputs during evaluation.
